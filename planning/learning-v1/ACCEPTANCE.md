# Acceptance without procedural inflation

The native task `completion_contract.required` lists are the canonical package acceptance requirements. They are not executable gates by themselves. Once real commands exist, the active owner binds them with the current `coordinate_task(action="bind_required_gates")` mechanism and completes through `finish_task`. Do not invent command paths before implementation, bypass the controller for GPU work, or treat this package checker as implementation acceptance.

## R — repaired inference instruments

Exercise the repaired native code, not copied formulas. Test nontrivial rectangular/right-nullspace orientation and scaling; persistent finite log weights with explicit zero-prior semantics; same independent evidence accumulated in different orders/batches. This last control does not assert time reversal of a filtering problem.

## L — real learning, not supplied-answer scoring

Infer shared law coefficients and local initial/hidden quantities from observations. Exercise missing channels, multiple instances, genuine held-out observables and at least one intentionally unresolved alternative. A new independent measurement should resolve a designed distinction without inventing prior certainty. Check complete-objective finite differences and adjoint identities on actual forward computations, including shared/repeated parameter contributions and stale-trace refusal. Check a zero-valued trainable coefficient does not accidentally erase its valid derivative support.

Show authorized local conditioning with frozen global learned values. Serialize logical fitted candidates and replay predictions in a fresh process. Demonstrate preparation reuse across ordinary value updates. Use one small end-to-end consumer before growing the abstraction.

## D — correct evidence semantics

Test original cell/sample identifiers, axes, modality/time/replicate, clone joins, exclusions, measured-zero versus missing, clone isolation across splits and source-derived preprocessing provenance. A common clone is not a known parent-child edge. Preserve unresolved time-label conflicts. Do not fit a joint RNA/ATAC representation for an RNA-only arm.

## P — a separate runnable pilot

Build outside the core build, against installed packages. No CE source inclusion, alternate production numerical engine or CellTag constants in core. Run the selected protocol and equal-evidence controls on a bounded real subset when available. Otherwise execute explicitly synthetic format fixtures, preserve a real-run configuration and exact missing-input manifest, and report biology as `not_run_inputs_unavailable`. Fixtures qualify wiring/semantics, not biological claims.

## A — one integrated qualification

Bind the actual affected native tests and external-client checks; retain final source/build/test receipts, selected CE route and actual CUDA coverage. Measure a bounded fitting lifecycle/iteration and visible data movement. Do not claim speedup from toy-kernel timing or infer learning capability from a header.

A completion report must separately state:

- **Toolkit:** implemented/reused capabilities, actual installed tests and unresolved blockers.
- **Experiment client:** adapter/protocol/build status, with fixture versus real input explicit.
- **Biology:** actual cohort, authorized evidence, results and limitations, or why no real run occurred.

`no_change_required` is an evidence-backed disposition, never a substitute for testing. Missing CUDA validation blocks claims about that CUDA route. Absence of public biological inputs need not block a correctly qualified general learning toolkit. No scientific improvement over baselines is demanded merely to accept engineering work.
