# Learning and conditioning protocol

The first engineering qualification uses controlled, partial observations. Shared law values and local state/forcing quantities are declared independently from their inference treatment. An ordinary Torch optimizer fits them from permitted observations, with a sanctioned CelleraTorch update for native-owned values. This fixture is a test of the inference client and execution path, not a CellTag result.

Global fitting uses discovery evidence only. Local conditioning freezes shared parameters and checks the permitted modality, split and prospective cutoff. A held-out target or ATAC-derived input is rejected. Retrospective conditioning must explicitly name later supplied evidence; it is not prospective prediction. Zero observations remain observed, and absent channels are masked rather than asserted zero.

A product-law fixture r=k*x*z*f has a learned shared k and local unknown z and effective forcing f. Observing their product does not generally identify z and f separately. Whole alternatives with the same product are preserved; a separately authorized observation of z can resolve that ambiguity. The actual native training fixture and native readout compare the same saved values and scalar response, with forcing held fixed where required by the bounded operator contract.

The checkpoint saves native values through their actual owner and ordinary Torch state through framework facilities. A GH manifest records scientific identity, domains, evidence permissions, supported response capabilities and unresolved alternatives. Rebuilding preparation in a fresh process must reproduce predictions; live pointers/streams are not scientific state.

The native boundary is a public installed GH typed system/readout and published CE arithmetic/differential package. A selected response is qualified directly; unsupported general transformations stay explicit. The experiment package remains outside the core dependency graph. Biological inputs are missing as recorded by the separate CellTag input contract, so biological status remains not_run.
