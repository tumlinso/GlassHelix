# CellTag inputs and permitted use

No CellTag count archive, clone-call table or corresponding sample/cell metadata is present in this checkout. A targeted inventory found only unrelated Tabula Sapiens preprocessing references. The first invocation will therefore audit synthetic format fixtures; biological fitting is not_run.

Required real inputs are processed iEP RNA from [GSE216518](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE216518), original sample time/replicate/regime annotations, original source cell identifiers, and released corrected clone membership with method/version provenance. RNA descriptions identify 25 samples, including four separate day-14 Zfp281 perturbation/control samples; the provisional common-forcing arm excludes those four. They are not another elapsed time of the same regime. The approximately 1 GB RNA archive and matching clone metadata are not locally downloaded or joined.

Independent validation requires processed iEP ATAC from [GSE217119](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE217119) and its sample/cell/clone membership. Its approximately 2.4 GB archive has 29 samples. Sharing a time label does not pair RNA and ATAC cells. Preserve original day labels: the paper's days 3/12/21 and methods day 11 discrepancy remains unresolved provenance rather than silently adjusted intervals.

The author study [CellTag-multi](https://www.nature.com/articles/s41587-023-01931-4) reports lineage-linked evidence; a barcode relation is ancestry metadata, not a complete parent-child history. Clone calls must record whether withheld expression or ATAC values contributed to assignment. No local exact corrected clone-assignment archive identity is verified. These metadata are indispensable for leakage audit and lineage validation.

The standardized CSV client accepts already processed long-form observations rather than replacing an H5/count preprocessing package. Original sample, cell, clone, modality, replicate, feature and time identifiers remain visible. The real producer must create this CSV with source hashes and preprocessing/QC provenance; the client hashes the actual supplied CSV. Frozen RNA-only authorized features and clone-disjoint splits prevent target/ATAC access. Fitting transforms on training records is required before any real run. Missing observations remain absent values, including measured zero as observed.
