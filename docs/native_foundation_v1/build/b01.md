# B01 native scientific library

The default target is GlassHelix::foundation, a compiled static library with
required_host_dimensions and bind_host_instance exported from host_bindings.cc.
A separately linked gh_nf1_b01 consumer invokes both functions. Role-aware extent
validation rejects mismatched state/parameter bindings and overflow before
allocation; independent host values share an immutable scientific definition.
Observed zero/nonfinite values are preserved without numerical reinterpretation.
This host scientific binding does not allocate device state or replace Cellerator
execution, storage or tensor owners.

GlassEtch is no longer a default build target. Historical source and its old root
wiring remain available only through explicit GH_BUILD_LEGACY=ON. The existing
NF1_HOST_VALIDATION option continues to select the independent oracle owner.
No existing experimental entry point, token Cell or sparse helper enters the
native library. A default CUDA demo is future assembly work and must require
actual CUDA when delivered; no demo fallback is introduced here.

The isolated B workspace consumes immutable C-lane contracts at commit
37d06cfe56f980046560450fd5f3298fc2242fff via GH_NF1_CONTRACT_ROOT plus the required
GH_NF1_CONTRACT_COMMIT pin. No C files were copied or merged into this artifact.
After central integration, GH_NF1_CONTRACT_ROOT defaults to the current project
and uses its own headers. CELLERATOR_SOURCE_ROOT explicitly selects the integrated
Cellerator checkout. b01-inputs.json pins the tested external headers and commits;
these references qualify this isolated build, not any changed descendant build.

Configure the integrated source with CELLERATOR_SOURCE_ROOT set to the producer
checkout (or environment for the native preset), build the native preset and run
ctest --preset native. Installed package/export consumer qualification remains
B02 and later work after the real Cellerator execution import.

Validation used CMake 3.28.3, GNU C++13.3, Release, two build jobs, and actual
nonempty gh_nf1_b01 CTest execution. Cases cover independent values, shared
scientific definition, role-derived sizes, observations not entering state size,
null/mismatched bindings, empty definitions, overflow rejection, and nonfinite
preservation. nm confirms two real compiled public symbols. A separate configure
negative control rejected an incorrect external contract commit. Native gate
receipts are external and source-bound; no CUDA/performance claim is made.
