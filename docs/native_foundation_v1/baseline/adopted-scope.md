# NF1 adopted engineering scope

Reviewed for GH-NF1-A01 on 2026-09-09 against source base
25e885510e127540ab4498e9f495dc989654c9a1 and the accepted
planning/native-foundation-v1 package. This adopts an execution toolbox, not
an experiment, trained biological model, or claim that foundational science is
settled. GH-SCIENCE-FOUNDATIONS remains independently unresolved; NF1 neither
rewrites that task nor declares its scientific questions solved.

GlassHelix owns scientific system and mechanism identities, observation and
inference roles, supplied dynamics, questions, and interpretation. Cellerator
owns numerical operation semantics and prepared CPU/CUDA execution, resources,
support/projection realizations and derivative actions. CellShard retains
storage/distribution and Baseplane sequence grounding. The legacy nested
extern/Cellerator gitlink is historical integration material, not the producer
authority. Reuse sound Cellerator owners before introducing new implementations.

The native C++20 path and thin Python access must execute the same implementation.
Provide deterministic discrete maps and fixed-step RK4 with explicit forcing,
nonlinear n-ary mechanisms, separate observation and finite inferential state,
local sensitivity/null-direction instruments, supplied reductions and candidate
reweighting. General-width FP32 includes width 33 and applicable empty/tail cases;
an independent FP64 CPU oracle checks arithmetic. The default integrated demo
requires actual CUDA. A descriptor, syntax shell, fake provider or independent
reference executable alone does not establish a native capability.

Preparation freezes admitted structure; bindings carry independent values and
state. Preserve snapshot reads, epochs, generations, effects and branch decisions.
Scientific identity is not kernel identity, equal shape is not domain equality,
and sharing storage or work must not merge explanations or individuals. Activity
zero is not predicate exclusion for nonfinite values and may retain sensitivity.
Unsupported derivative/object combinations fail explicitly. Differentiated objects,
scales, precision, tolerances and approximation domains must be recorded.

Persistent support plus explicit activity is the first baseline, with exact
compact-active comparison and structural replacement qualification. These are
engineering realizations, not biological ontology. Local null directions do not
prove global equivalence or mechanism identifiability. Predictive latent state,
observability, population snapshots and reconstruction accuracy must not be
silently promoted to molecular mechanism, individual trajectories or causality.

No NF1 task selects fibroblast biology, acquires an experimental dataset, chooses
a final learner, claims exhaustive mechanism recovery, builds a general compiler,
or begins distributed execution. Stochastic/stiff/delay solvers and general
Bayesian inference remain future extensions with honest unsupported behavior.

Qualification joins real producer commits and consumer evidence. Closure order is
CE M50 consumer-ready, GH M60 consumer acceptance, CE M90 final, GH M90 final.
Receipts bind source dependencies, interface versions, executable/test provenance
and fresh authority checkpoints. This review is governance evidence only; it
claims no implemented runtime, numerical test pass or GPU performance result.
